# GigaChat Open Client ✨

Современный, легкий и полнофункциональный веб-клиент для работы с официальным **GigaChat API**.

> **Важно:** Это независимый проект с открытым исходным кодом. Он не является официальным продуктом ПАО Сбербанк.

---

## 🚀 Возможности

- **Прямое взаимодействие с GigaChat API:**
  - `GET https://api.giga.chat/v1/models` — динамическое получение и обновление доступных моделей.
  - `POST https://api.giga.chat/v1/chat/completions` — генерация ответов в формате OpenAI-compatible Chat Completions.
- **Безопасность и конфиденциальность:**
  - Архитектура **Frontend-only**: приложение работает целиком в браузере без посреднических серверов.
  - Ваши токены и ключи **никогда** не отправляются на сторонние сервера или прокси.
  - В репозитории и сборке отсутствуют захардкоженные токены или секреты.
  - **Access Token** хранится в браузерных cookie (`gigachat_access_token`) с параметрами `Path=/; SameSite=Lax`.
  - **Authorization Key** (опционально) хранится строго локально в `localStorage` и никогда не включается в экспорт.
- **Управление чатами:**
  - Локальное сохранение истории диалогов в `localStorage` (`gc_chats`).
  - Автоматическое наименование диалога по первому вопросу (до 40 символов).
  - Создание новых чатов, удаление диалогов.
  - Повтор последнего запроса (Retry) и копирование ответов в буфер обмена.
  - Экспорт истории чатов и настроек в JSON-файл (без токенов и секретов).
  - Импорт резервной копии с валидацией структуры данных.
- **Форматирование сообщений:**
  - Поддержка Markdown (заголовки, жирный/курсив, списки, цитаты, таблицы).
  - Блоки кода с кнопкой быстрого копирования и моноширинным шрифтом.
- **Интерфейс и адаптивность:**
  - Минималистичный дизайн в стиле современных AI-клиентов.
  - Тёмная (по умолчанию) и светлая темы с плавным переключением.
  - Полная поддержка мобильных устройств (iOS / Android) с выдвижным drawer-меню и адаптацией под safe areas (`100dvh`).

## 🔒 Безопасность и хранение токенов

1. **Где пользователь вводит Access Token?**
   В интерфейсе приложения по нажатию на иконку ⚙ **«Настройки»** (или на статус подключения в верхней панели).
2. **Где хранится токен?**
   Access Token сохраняется в cookie браузера:
   `document.cookie = "gigachat_access_token=...; Path=/; SameSite=Lax; Max-Age=..."`
   В настройках доступна кнопка **«Удалить сохранённый токен»**, которая мгновенно удаляет cookie.
3. **Предупреждение о безопасности cookie:**
   *Cookie доступна JavaScript и не является HttpOnly-хранилищем. Не вводите свои ключи на чужих или публичных компьютерах.*
4. **Срок действия токена:**
   *Access Token GigaChat является временным (~30 минут). После истечения срока действия необходимо вставить новый токен в настройках.*

## 🔑 Как получить Access Token GigaChat

Для работы с API вам потребуется токен доступа:

1. Зарегистрируйтесь на портале [Сбер Бизнес / Studio](https://developers.sber.ru/).
2. В личном кабинете создайте проект **GigaChat API** и получите **Authorization Data (Client ID / Client Secret)**.
3. Выполните запрос обмена ключа на временный `access_token` через cURL в терминале:

```bash
curl -L -X POST 'https://ngw.devices.sberbank.ru:9443/api/v2/oauth' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -H 'Accept: application/json' \
  -H 'RqUID: 12345678-1234-1234-1234-123456789abc' \
  -H 'Authorization: Basic ВАШ_AUTHORIZATION_KEY' \
  --data-urlencode 'scope=GIGACHAT_API_PERS' -k
```

> Скопируйте поле `access_token` из полученного ответа и вставьте его в поле **Access Token** в интерфейсе клиента.

## 🛠 Используемые API Endpoints

- **Базовый URL:** `https://api.giga.chat`
- **Список моделей:** `GET https://api.giga.chat/v1/models`
  - Заголовок: `Authorization: Bearer <ACCESS_TOKEN>`
- **Отправка сообщений:** `POST https://api.giga.chat/v1/chat/completions`
  - Заголовки:
    - `Content-Type: application/json`
    - `Authorization: Bearer <ACCESS_TOKEN>`
  - Тело запроса:
    ```json
    {
      "model": "GigaChat-2",
      "messages": [
        { "role": "system", "content": "..." },
        { "role": "user", "content": "..." }
      ],
      "temperature": 0.7
    }
    ```

## 💻 Локальный запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/gigachat-open-client.git
   cd gigachat-open-client
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

4. Откройте в браузере `http://localhost:3000`.

## ☁️ Деплой на Vercel

Проект полностью настроен для деплоя на [Vercel](https://vercel.com):

1. Загрузите код в ваш публичный или приватный репозиторий на GitHub.
2. В панели Vercel нажмите **«Add New Project»** и импортируйте репозиторий.
3. Vercel автоматически определит конфигурацию:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
4. **Environment Variables НЕ требуются** — оставьте раздел переменных пустым, так как токен вводится пользователем в интерфейсе и хранится локально в его браузере.
5. Нажмите **Deploy**.
